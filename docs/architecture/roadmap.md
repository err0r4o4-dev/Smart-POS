## Phase 5 delivery gates (2026-10-10)

- **5.1 COMPLETED (Local):** historical full/partial returns, exact cumulative allocation, approval/disposition, atomic Inventory/pending-refund/audit, explicit manual settlement/reconciliation and current-shift cash accounting. Latest 247 API assertions, 91 frontend tests, contracts/typecheck/lint/build, Go race and 19 browser regressions passed. Two routes added to implementation status, none to the canonical 106-route inventory.
- **5.2 COMPLETED (Local):** equal/positive/negative/multi-item historical-credit exchanges, explicit difference evidence/recovery, once-only cash totals, atomic linked Return/replacement Sale/Inventory, compensating full-sale reversals and immutable originals. 384 new API assertions, 996 numbered regression assertions, 94 frontend tests, 21 real browser tests, fresh migrations1–9/seven SQL suites and CGO race passed. Canonical16/106 unchanged.
- **5.3–5.6 NOT STARTED:** price lists/promotions; customers/privacy; loyalty ledger/reversal; tracked/untracked batches, expiry/recall and write-offs still required. Phase5.3 can be planned next with persisted historical discount/tax allocations and credit-aware reporting; this does not start implementation or authorize Phase6.
- **5.7 PARTIAL:** Phase0–5.2 regressions/concurrency/E2E/security passed locally, but missing subphase gates have not run. Phase5 overall cannot close; hardware, legal/tax and production-load certification remain outside this acceptance.
- Migration8 remains unchanged and contains Returns/Refunds only; new forward-only migration9 adds Exchanges/Voids. Readiness is exact clean9. Future additions need sequential migrations and renewed fresh-chain verification, never edits to applied migrations or migration of a primary verification target.
